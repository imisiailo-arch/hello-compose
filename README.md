# HelloCompose

Навчальний Android-застосунок, створений у межах лабораторної роботи №1.

## Тема лабораторної роботи

Встановлення Android Studio, створення першого Jetpack Compose-проєкту, налаштування GitFlow, Issue Templates та GitHub Actions CI.

## Мета роботи

Метою лабораторної роботи було налаштувати робоче середовище для Android-розробки, створити перший застосунок на Jetpack Compose, підключити Git-репозиторій, організувати роботу з гілками за підходом GitFlow, а також додати шаблони задач і CI-шаблон через GitHub Actions.

## Опис проєкту

HelloCompose — це простий Android-застосунок, створений мовою Kotlin із використанням Jetpack Compose.  
Після запуску застосунок виводить текстове привітання на екрані емулятора.

## Як запустити проєкт

1. Встановити Android Studio.
2. Встановити Android SDK API 26 або вище.
3. Клонувати репозиторій:

```bash
git clone https://github.com/imisiailo-arch/hello-compose.git
